Privacy Policy

Last updated: November 4, 2026

Summary

Embergard is an on-device security application. It does not collect, transmit, sell, or share your personal data. All processing happens locally on your device.

Data We Process

Embergard processes the following data locally on your device:

  • Network traffic — inspected via VPN for PII exfiltration detection. Packet contents are not stored.
  • SMS messages — scanned for phishing URLs. Content processed in-memory only, not persisted.
  • Notifications — analyzed for phishing indicators. Processed in-memory, not stored.
  • Installed apps — enumerated and checked against malware signature databases. Only app package names and permission lists are analyzed.
  • File hashes — computed on-device for malware scanning. File contents are not uploaded.
  • Device integrity — Play Integrity API and root detection results, stored encrypted on-device.

What We Don't Do

  • No cloud servers — all processing is on-device
  • No analytics or crash reporting SDKs
  • No advertising or ad SDKs
  • No selling or sharing data with third parties
  • No tracking or profiling
  • No PII retention — user hardline policy

Permissions

Embergard requests the following restricted permissions for its security features:

  • SMS (READ_SMS, RECEIVE_SMS) — SMS phishing detection
  • Contacts (READ_CONTACTS) — Data exfiltration detection
  • Call log (READ_CALL_LOG) — Stalkerware detection
  • Notifications (BIND_NOTIFICATION_LISTENER_SERVICE) — Notification phishing detection
  • All packages (QUERY_ALL_PACKAGES) — Full-device malware scanning
  • Storage (MANAGE_EXTERNAL_STORAGE) — Malware file scanning
  • VPN (BIND_VPN_SERVICE) — Deep packet inspection

Each permission is essential for core security functionality. No permission is used for advertising, analytics, or data sales.

Data Encryption

All stored data is encrypted with AES-256-GCM using hardware-backed keys from the Android Keystore. Keys are periodically rotated. Network traffic uses TLS with certificate pinning.

Data Deletion

To delete all Embergard data: uninstall the app, or use the in-app "Wipe all data" option in Settings. This removes all encrypted data immediately.
