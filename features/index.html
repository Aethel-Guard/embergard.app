EG-04.1 / Capabilities

Five capabilities. One principle.

🌐

Deep Packet Inspection

Real-time VPN-based DPI monitors all network traffic. Detects PII exfiltration, cleartext HTTP, and blocked destinations — all on-device.

🎣

Phishing Detection

Scans SMS, notifications, and URLs for phishing attempts using on-device ML. No content ever leaves your phone.

👀

Stalkerware Scanning

Detects spyware and stalkerware by analyzing app permission patterns. Identifies apps that shouldn't have access to your camera, mic, or location.

🔐

Encrypted Vault

All security data is encrypted with AES-256-GCM via Android Keystore. Hardware-backed keys with periodic rotation.

⚖️

Dual Sign-Off Governance

Every assessed operation requires dual sign-off (operator + cybersec agent). Full audit trail for accountability.
